Instrucciones para la eliminación de datos de Luma Code

Última actualización: 22 de septiembre de 2026

Las personas que hayan utilizado Luma Code pueden solicitar la eliminación de sus datos personales asociados al servicio.

Cómo solicitar la eliminación

Envía un correo electrónico a alfonadeccco@gmail.com con el asunto “Solicitud de eliminación de datos - Luma Code”.

Incluye únicamente la información necesaria para poder identificar los datos cuya eliminación solicitas, por ejemplo el número de teléfono utilizado para comunicarte con Luma Code mediante WhatsApp.

Qué ocurrirá con la solicitud

Se verificará la solicitud cuando sea necesario para evitar la eliminación no autorizada de información perteneciente a otra persona. Una vez identificados los datos correspondientes, se procederá a su eliminación cuando legalmente corresponda.

Datos que deban conservarse

Determinada información podrá conservarse durante el tiempo estrictamente necesario cuando exista una obligación legal, sea necesaria para formular, ejercer o defender reclamaciones, o concurra otra causa legítima prevista por la normativa aplicable. Cuando proceda, el acceso a dicha información quedará limitado a la finalidad que justifique su conservación.
