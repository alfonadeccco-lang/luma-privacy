Política de privacidad de Luma Code

Última actualización: 22 de septiembre de 2026

1. Responsable del tratamiento

Responsable: Alfonso Calvo Romero
Proyecto/servicio: Luma Code
País: España
Contacto de privacidad: alfonadeccco@gmail.com

2. Qué información podemos tratar

Luma Code puede tratar los datos que una persona facilite voluntariamente al utilizar el servicio o comunicarse con él, incluidos datos de contacto, identificadores técnicos y de mensajería, mensajes y archivos o documentos enviados por el usuario.

Cuando el usuario decida remitir documentación que contenga información sobre su salud, dicha información puede constituir una categoría especial de datos personales. Luma Code no solicita al usuario que envíe información de terceros sin contar con una base legítima para hacerlo.

3. Uso de WhatsApp

Luma Code puede utilizar WhatsApp y los servicios de Meta como canal de comunicación y recepción de información. Cuando el usuario envía voluntariamente un mensaje o documento a través de WhatsApp, pueden tratarse los datos necesarios para recibir, identificar, proteger frente a duplicados, conservar la procedencia y procesar técnicamente dicho contenido dentro del servicio.

El uso de WhatsApp también está sujeto a las condiciones y políticas de privacidad aplicables de WhatsApp y Meta.

4. Finalidades

Los datos se tratarán para prestar y desarrollar las funcionalidades solicitadas por el usuario; recibir y procesar técnicamente mensajes y documentos; mantener su integridad, trazabilidad y seguridad; responder a solicitudes relacionadas con el servicio; prevenir errores, duplicados o usos indebidos; y cumplir obligaciones legales aplicables.

La información no se utilizará para publicidad de terceros ni se venderá a terceros.

5. Datos relativos a la salud

Cuando el servicio implique el tratamiento de datos relativos a la salud facilitados por el propio interesado, dicho tratamiento se realizará únicamente cuando exista una base jurídica válida conforme a la normativa aplicable y, cuando sea necesario, consentimiento explícito para las finalidades correspondientes.

El envío de un documento por WhatsApp no sustituye por sí solo los mecanismos de consentimiento que puedan ser legalmente necesarios para funcionalidades que impliquen el tratamiento de categorías especiales de datos.

6. Base jurídica

Según la funcionalidad y el contexto, el tratamiento podrá basarse en el consentimiento del interesado, en la ejecución de medidas o servicios solicitados por éste, en el cumplimiento de obligaciones legales o en otra base jurídica válida prevista por la normativa aplicable. Para categorías especiales de datos se aplicarán adicionalmente las condiciones exigidas por el artículo 9 del RGPD.

7. Destinatarios y proveedores

Para operar el servicio pueden intervenir proveedores tecnológicos que actúen como encargados o proveedores de infraestructura, exclusivamente en la medida necesaria para prestar sus servicios. Cuando WhatsApp sea utilizado como canal, Meta Platforms y las entidades correspondientes de WhatsApp intervienen en el transporte y funcionamiento de la mensajería conforme a sus propias condiciones y a la relación jurídica aplicable.

No se comunicarán datos personales a otros terceros salvo cuando sea necesario para prestar una funcionalidad solicitada, exista una obligación legal o concurra otra base jurídica válida.

8. Transferencias internacionales

Algunos proveedores tecnológicos pueden tratar datos fuera del Espacio Económico Europeo. Cuando resulte aplicable, se utilizarán los mecanismos y garantías exigidos por la normativa de protección de datos para dichas transferencias.

9. Conservación

Los datos se conservarán únicamente durante el tiempo necesario para las finalidades para las que fueron recogidos, para mantener la integridad y continuidad del servicio y durante los plazos adicionales que puedan resultar necesarios para cumplir obligaciones legales o atender responsabilidades. Cuando los datos dejen de ser necesarios, serán eliminados o anonimizados conforme a los procedimientos aplicables.

10. Seguridad

Luma Code aplica medidas técnicas y organizativas orientadas a proteger la confidencialidad, integridad, disponibilidad y trazabilidad de la información y a reducir el riesgo de acceso, alteración, pérdida o divulgación no autorizados.

11. Derechos de las personas

El interesado puede solicitar, cuando corresponda, el acceso a sus datos personales, su rectificación o supresión, la limitación u oposición al tratamiento y la portabilidad de sus datos, así como retirar el consentimiento cuando el tratamiento se base en él, sin afectar a la licitud del tratamiento anterior a su retirada.

Para ejercer estos derechos o realizar cualquier consulta sobre privacidad puede escribir a alfonadeccco@gmail.com. También puede presentar una reclamación ante la autoridad de protección de datos competente.

12. Menores

Luma Code no está dirigido específicamente a menores de edad. Cuando la normativa exija autorización de padres, tutores o representantes legales para un determinado tratamiento, ésta deberá obtenerse antes de realizarlo.

13. Decisiones automatizadas

Esta política no implica que Luma Code adopte decisiones con efectos jurídicos o significativamente similares sobre una persona de forma exclusivamente automatizada. Si en el futuro se incorporase una funcionalidad de ese tipo, se proporcionaría la información y las garantías exigidas por la normativa aplicable antes de su utilización.

14. Cambios en esta política

Esta política podrá actualizarse cuando cambien las funcionalidades, proveedores o requisitos legales. La versión vigente estará disponible públicamente en esta misma ubicación o en la URL que la sustituya.
